# Seguridad

Si encuentras una vulnerabilidad de seguridad, no publiques credenciales, tokens, datos personales o información sensible en un issue público.

Mientras el proyecto se encuentre en desarrollo, reporta los problemas de seguridad al responsable del repositorio mediante un canal privado disponible en GitHub.

Nunca incluyas:

- contraseñas;
- tokens o claves API;
- credenciales de base de datos;
- imágenes o datos personales reales de empleados;
- bases de datos de producción.
